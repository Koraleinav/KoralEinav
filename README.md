## 🚀 What I've Been Working On

- **Datarails Desk** - an AI-powered helpdesk product for finance teams. Built the backend as an async FastAPI microservice (SQLAlchemy 2 + Alembic, PostgreSQL, Redis, Taskiq background workers) and the frontend as an Angular micro-frontend loaded into the platform shell via Module Federation.
- **Email ingestion gateway** - a FastAPI microservice that turns inbound email into platform events: SendGrid Inbound Parse webhooks, attachment upload to Azure Blob Storage, and event publishing to Azure Service Bus, secured with Azure Key Vault and managed identities.
- **FinanceOS platform** - features and microservice extraction across the core platform: Django + DRF + Celery backend and Angular 16 web apps (Module Federation shell + remotes).
- **Cloud infrastructure & delivery** - Terraform/Terragrunt on AKS, GitHub Actions CI/CD pipelines, feature-flagged rollouts (Unleash), and observability with OpenTelemetry and structured logging.
